# Links-System 利用マニュアル

初めて利用する社内ユーザー向けの、画面付きHTMLマニュアルです。

- 配信URL: `/manual/`
- 入口: `index.html`
- 動的操作: `manual.js`
- 画面・印刷スタイル: `manual.css`
- 画面例: `screenshots/`（匿名の検証データのみ）

## 更新時の確認

1. 現行コードと `仕様MD/` を照合し、実装済みの操作だけを書く。
2. 現行25機能すべてに目的、担当、具体例3件、前後関係、似た機能との違いを用意する。テストで現行機能カタログとの一致を確認する。
3. ローカルリンク、画像、章IDを `backend/test/manual.test.js` で確認する。
4. Docker環境でシステムの「利用マニュアル」から新しいタブが開くことを確認する。
5. 「この章を印刷」と「全体を印刷」をPDF出力し、A4の改ページと画像切れを確認する。

開発者向けの起動・環境資料は `docs/manual/developer.html` を参照してください。

## 2026年9月25日の更新

25機能・75例に拡充。日報入力改善、Excel出入、計算ルール、役割別メニュー、基本管理を現行mainに合わせました。OCR・燃料費・年度締めは計画段階として区別しています。

画面再取得は匿名検証環境だけで行います。`UI_BASE_URL`、`MANUAL_YM`、検証用の認証情報と `MANUAL_ANONYMOUS_CONFIRMED=1` を環境変数へ設定し、`npm run capture:manual --prefix backend` を実行します。生成や登録は行わず、画面を閲覧して保存します。対象データがなく詳細を開けない画面は、更新した一覧画像を使い、古い画像を最新と表示しないでください。
