# Links-System 利用マニュアル

初めて利用する社内ユーザー向けの、画面付きHTMLマニュアルです。

- 配信URL: `/manual/`
- 入口: `index.html`
- 動的操作: `manual.js`
- 画面・印刷スタイル: `manual.css`
- 画面例: `screenshots/`（匿名の検証データのみ）

## 更新時の確認

1. 現行コードと `仕様MD/` を照合し、実装済みの操作だけを書く。
2. 18機能すべてに目的、担当、具体例3件、前後関係、似た機能との違いを用意する。
3. ローカルリンク、画像、章IDを `backend/test/manual.test.js` で確認する。
4. Docker環境でシステムの「利用マニュアル」から新しいタブが開くことを確認する。
5. 「この章を印刷」と「全体を印刷」をPDF出力し、A4の改ページと画像切れを確認する。

開発者向けの起動・環境資料は `docs/manual/developer.html` を参照してください。
