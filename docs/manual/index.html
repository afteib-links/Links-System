運送業務基幹システム

Links-System
操作マニュアル

初めて使う人が、画面を見ながら「何をどこに入れるか」を確認するための資料です。

今回の確認用見本は 日報（一覧1ページ・入力1ページ）です。ほかの機能は同じ型で後から足します。

対象版: 現行SPA（左サイドバー） / 作成日: 2026-09-09

開発者向け（起動・設定・記入例）は developer.html です。

1. このシステムの考え方

Links-System は、運送・作業の代行会社が、現場の実績から請求・支払までを一本化する業務システムです。紙やExcelで分かれていた「いつ誰が何をしたか」と「いくら請求・支払するか」を、同じ案件の流れで扱います。

中心になるのは 日報 です。日報は勤務時間のメモではなく、請求額と支払額の根拠です。同じ勤務実績を使い、請求先企業向けの単価とパートナー向けの単価は別々に計算します。

層意味（利用者向け）
実績日付、開始・終了、休憩、距離、経費など、現場で起きたこと
計算ルール案件に紐づく料金セット。曜日や休日で候補が選ばれる
確認・承認入力者が日ごとに確認し、案件×月でまとめて承認する
精算承認済み日報から請求・支払を作り、帳票と入出金へ進む
注釈。 画面に出る金額は、取込ファイルや手書きの合計額ではなく、システムが案件の料金設定から再計算した結果です。

2. 業務の流れ

マスタ整備（企業 → パートナー → 基本案件 → 個別案件 → 金額データ） → 日報一覧で対象月・案件を選ぶ → 日報入力（代理入力または Excel/CSV 取込） → 日次確認 → 月次承認 →（分割案件なら）先払 → 請求 / 支払の下書き → 確認 → 最終確定・PDF → 入出金の予定・実績

ログイン後は左メニューが機能の入口です。マスタが無い案件は日報に出ません。日報が未承認の月は、請求・支払の本番確定の根拠になりません。

注意。 メニューの「日報」と「日報提出」は別物です。日報は勤務内容の入力、日報提出はパートナーから届いた紙・メールの受領チェックです。入力した件数から提出済みにはなりません。

3. この資料の見方

機能ごとにHTMLを分けています。一覧で探す画面と、詳細を入れる画面は別ページです。各ページは次の順です。

  1. この画面の役割
  2. 誰が・いつ使うか
  3. 具体例（架空の検証用データ）
  4. 画面イメージ（オレンジの番号は説明用）
  5. 何をどこに入れるか
  6. 操作手順
  7. 注釈・注意

青枠は補足、橙枠は誤操作を防ぐ注意です。画面画像は検証用の匿名データです。実在の顧客名・口座は使いません。

5. 開き方

このHTMLはアプリ本体ではありません。ブラウザでファイルを開くだけで読めます。社内LANのアプリは通常 http://<NASのIP>:8080 です。操作そのものはアプリ側で行います。

  1. このポータルから対象の機能ページを開く
  2. 画面イメージの番号と表を照合する
  3. アプリにログインし、左メニューから同じ機能を開いて手順どおり操作する
注釈。 左メニューに出る機能は権限で変わります。企業ロールでは日報は出ません。取込ボタンは管理者・総務だけです。
