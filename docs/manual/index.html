2. ログインと画面の骨格

ログイン

ログインIDとパスワードで入ります。無効ユーザーは入れません。成功するとセッションに権限が載り、左メニューには使える機能だけが出ます。

するとどうなる
正しいID/パスワードでログインホーム（業務ダッシュボード）が開く。権限のない機能はメニューに出ない
IDまたはパスワードを間違える同じ画面にエラーが出て、入れない
パスワードの表示切替入力中の文字の見せ方だけ変わる。ログイン自体は変わらない
ログアウトセッションが終わり、ログイン画面に戻る

ログイン後の骨格

左が機能メニュー（マスタ / 日々の運用 / 精算 / 設定）、上がユーザー名と権限、右下が本文です。☰ でメニューを折り畳めます。狭い画面ではメニューがオーバーレイになります。

するとどうなる
左の機能名をクリックその機能の一覧（またはハブ）が本文に出る。URLは変わらない
ブランド「Links-System」またはホームダッシュボードに戻る
年月ナビ（各業務画面）表示対象月が変わり、一覧・集計がその月になる

3. ホーム（業務ダッシュボード）

当月の進捗カードと、「次に処理する項目」です。カードをクリックすると対応する機能へ進みます。

するとどうなる
進捗カードをクリックその機能（日報・請求など）が開く
「次に処理する項目」をクリック未完了や要対応がある機能へ飛ぶ
権限のない機能のカード集計対象に含まれない（見えない）

4. 企業マスタ

メニュー「マスタ → 企業マスタ」。請求先となる企業の台帳です。車両・担当履歴もここで持ちます。

使える権限: 管理者 / システム担当者 / 総務

するとどうなる
一覧で行または詳細を開くその企業の編集画面になる
新規企業登録 → 保存企業が追加され、以降の案件・請求の候補になる
項目を直して保存台帳が更新される（請求書の宛名などに使われる）
車両や担当を追加その企業に紐づく車両・担当が増える。案件の車両選択の候補になる

5. パートナーマスタ

メニュー「マスタ → パートナーマスタ」。ドライバー・外注先の台帳、口座、車両です。支払・先払・日報の相手先になります。

使える権限: 管理者 / システム担当者 / 総務

するとどうなる
新規 → 保存パートナーが増え、案件の割当候補になる
口座・確定申告区分を保存支払・振込まわりの表示・控除の前提データになる
車両を追加所有がパートナー側の案件で、その車両を選べるようになる

6. 基本案件

メニュー「マスタ → 基本案件」。繰り返し契約のひな形（勤務時間・休憩・締日・既定の金額データの型）です。実稼働の契約そのものではありません。

使える権限: 管理者 / システム担当者 / 総務 / 営業

するとどうなる
基本案件を新規保存ひな形が増える。まだ日報や請求の対象にはならない
ひな形に金額データ（PriceSet）を付ける個別案件へコピーするときの料金の元になる
個別案件側で「基本から複製」属性と金額データがディープコピーされ、実行用の個別案件ができる

7. 個別案件

メニュー「マスタ → 個別案件」。企業・パートナー・期間が載った実行契約です。日報・先払・請求・支払はすべてここにぶら下がります。

使える権限: 管理者 / システム担当者 / 総務 / 営業

するとどうなる
個別案件を保存（企業・パートナー・期間）その月から日報の対象行に出せる
支払区分を「分割」にする先払画面のマトリクスに、稼働0日でも載る
金額データを期間付きで紐付ける日報入力時、その日の日付に合う単価が自動で選ばれる
車両の所有元（企業/パートナー）と車両を保存所属と矛盾する車両は選べない

8. 金額データ管理

メニュー「マスタ → 金額データ管理」。適用期間付きの料金セット（PriceSet）と、曜日・計算区分ごとの請求／支払単価行です。

使える権限: 管理者 / システム担当者 / 総務 / 営業

するとどうなる
金額データを新規し期間を入れるその期間の日報にこのセットが候補になる
料金行（基本・残業・深夜など）を保存日報の自動計算がこの単価を使う
日報側で一時的に単価を上書きその日だけ手入力が勝ち、セット本体は変わらない

9. 日報

メニュー「日々の運用 → 日報」。月次の案件一覧から、案件ごとの日別グリッドへ入ります。金額は画面の外の計算ロジックで再計算されます（取込ファイル内の請求額・支払額は使いません）。

使える権限: 管理者 / システム担当者 / 経営者 / 総務 / 営業 / パートナー（企業権限では開けない）

月次一覧

するとどうなる
対象月を変えるその月の案件と入力進捗が出る
案件の「入力」などを開くその案件の日別グリッドになる
絞り込み（締日・状態）一覧の行が減る。データは消えない

日報入力グリッド

するとどうなる
開始・終了・休憩・距離・経費を入れて保存その日の下書きが残り、残業・深夜などが再計算される
「この日を確認」その日が確認済みになる。警告があっても続行確認できる
「この日の確認解除」確認済みが下書きに戻り、また直せる
「月次承認依頼」未確認日があると警告。続行すると承認待ちになる
「月次承認」 / 「差戻し」承認済みになる、または差戻し理由付きで入力側に戻る
金額確認計算結果の点検用表示。確定そのものではない

Excel / CSV 取込

日報画面内。管理者・総務だけが取込操作できます。経営者は原本の閲覧側です。

するとどうなる
ファイルをアップロード原本が保存され、解析バッチができる。同一内容なら二重取込警告
列マッピングを決めるExcel列と日報項目の対応がバッチに載る（保存済み対応の再利用可）
「選択行を日報へ反映」下書き日報に値が入り、金額はシステムの計算で付け直される
反映済み・取消済みの適用ボタン押せない（再適用しない）

11. 請求
