日々の運用 → 日報 → 入力

日報入力

1つの個別案件について、対象月の毎日の実績を入れる画面です。入力した内容が請求・支払の根拠になります。

業務の流れでは「実績入力 → 日次確認 → 月次承認」にあたります。

1. この画面の役割

画面タイトルは「日報入力（案件#番号 / 年月）」です。表の1行が、その日の作業です。同じ日に作業を分けるときは行を追加します。

開始・終了・休憩・距離・経費を入れると、稼働・超過・不足と金額は自動で出ます。計算の中身を手で組み立てる必要はありません。

2. 誰が・いつ使うか

誰いつ
総務・事務手書き日報やFAXを代理入力するとき。毎日または締め前にまとめて
パートナー自分の案件の実績を入れるとき（権限がある場合）
承認担当月次承認や差戻しをするとき。金額確認で内訳を見るとき

3. 具体例

例1 — FAXの1日分を代理入力する

2026年8月3日（月）、開始 8:00、終了 17:00、休憩 1:00、距離 120 km、通行料 1,500 円と書いてあるとします。該当日の行に同じ値を入れ、「行保存」または「一括保存」します。稼働時間は自動計算されます。問題なければ状態バッジをクリックして、その日を確認済みにします。

例2 — 夜勤で日付をまたぐ

勤務日の 20:00 から翌朝 4:00 までの場合、終了は翌日の 4:00 ではなく 28:00 と入れます（勤務日基準。最大 47:59）。翌日の行へ分けません。

例3 — 月末に承認依頼する

対象月の日を確認し終えたら、上部の「月次承認依頼」を押します。未確認の日が残っていても警告のあと続行できます。承認担当は同じ画面の「月次承認」または「差戻し」を使います。請求・支払は、月次承認のあとに別メニューで進めます。

4. 画面イメージ

一覧の「入力」から開いたグリッドです。土曜は薄い青、日曜・祝日は薄い赤です。

場所すること
1上部の操作月次承認依頼 / 承認 / 差戻し、一括保存、データ取り込み、金額確認、一括表示、一覧へ
2▶その行の詳細（料金区分・深夜・契約単価・コメント）を開く
3不要・研修休む日は「不要」。研修日は「研修」にチェック
4開始・終了・休憩時刻を入れる。左右の − / ＋ で刻み増減。ダブルクリックで案件の基本時刻
5距離・通行料・駐車料・交通費距離は整数 km。経費は円
6状態クリックでその日の確認 / 確認解除。右の ＋ で同じ日に作業行を追加

稼働・超過・不足（請求）と日別の請求合計・支払合計は自動表示です。手入力しません。

6. 行の詳細（▶ で開く）

通常の日は表だけで足ります。料金の種類を変える、深夜休憩を入れる、その日だけ単価を変える、行のメモを残すときは ▶ を開きます。

ブロック入れるものメモ
料金区分料金名の選択曜日・休日から自動候補。手動変更できる。自動/手動の別が表示される
深夜時間深夜帯内休憩、必要なら深夜時間調整請求と支払で深夜帯が違うときだけ欄が分かれる
契約料金空欄のままが通常。一時変更するときだけ数値灰色の「元:」は契約単価。変更理由が必須。マスタは変わらない
計算結果（表示のみ）請求・支払の内訳の見方。確定ボタンではない
行コメントその日の補足月全体の連絡は別のメモ欄がある場合がある
行保存 / この日を確認ボタン確認後は金額関連がロック。直すときは確認解除
注釈。 「金額確認」は月の計算結果を点検する表示です。請求確定や振込ではありません。

7. 操作手順

毎日の入力

  1. 日報一覧 から対象案件の「入力」を開く
  2. 対象日の開始・終了・休憩、必要なら距離と経費を入れる
  3. 時刻欄をダブルクリックすると、案件に登録した基本時刻が入る
  4. 「行保存」または上部の「一括保存」を押す
  5. 内容が正しければ状態バッジ（または「この日を確認」）で日次確認する

月の締め

  1. 未確認の日が無いか見る。上部に稼働日数などの集計が出る
  2. 「月次承認依頼」を押す。未確認が残ると警告が出る。続行できる
  3. 承認担当が内容を見て「月次承認」する。問題があれば差戻し、行に指摘を残す
  4. 差戻し後は修正して、直した日を再確認してから再申請する
  5. 「一覧へ」で月次一覧に戻る。請求・支払は精算メニューへ進む

8. 注釈・注意

注釈。 休憩は1日の合計です。10時〜10時15分と12時〜13時のように区間登録しません。
注釈。 料金種類を変えると、保存前でもその行の金額表示が新しい単価で更新されます。前の料金に対する一時単価は引き継ぎません。
注意。 日次確認済みの間は、時間・距離・単価など金額に効く項目を直せません。直すときは確認を外してから編集し、もう一度確認します。備考など一部は確認後も直せます。
注意。 月次承認済みは案件×月の全体がロックされます。訂正は承認の取消し（権限と理由が必要）のあとです。承認後にマスタ単価を変えても、過去の確認済み内容は変わりません。
注意。 「日報提出」の提出済みチェックは、この画面の入力件数から自動では付きません。受領管理は別メニューです。
