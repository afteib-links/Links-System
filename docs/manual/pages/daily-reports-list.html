日々の運用 → 日報

日報一覧

対象月の案件を探し、入力画面へ進むための一覧です。ここで勤務時間は入れません。

業務の流れでは「マスタ整備のあと、実績を入れる入口」にあたります。

1. この画面の役割

1行は 個別案件 × 対象月 です。その月に日報を入れる相手（企業・パートナー）と、入力の進み具合、月次承認の状態を確認します。

一覧から「入力」を開くと、その案件の1か月分グリッド（日報入力）へ進みます。

2. 誰が・いつ使うか

誰いつ
総務・事務FAXやメールの日報が届いた日。未入力や差戻しを片付けるとき
営業担当案件の進捗を見るとき
承認担当（管理者・経営者など）確認待ちや要対応の件数を見るとき
パートナー自分に割り当てられた案件だけを見るとき（権限による）

使える権限: 管理者 / システム担当者 / 経営者 / 総務 / 営業 / パートナー。企業ロールではメニューに出ません。

3. 具体例

例1 — 未入力だけを片付ける

【検証】東都物流の案件で、2026年8月の日報がまだ無いとします。対象月を 2026年8月 にし、集計カード「未入力」をクリックします。一覧が未入力だけになるので、行の「入力」を押してグリッドへ進みます。

例2 — 締日が同じ案件だけ見る

5日締めの案件だけ先に入力したいときは、締日の選択を「5日」にして「絞り込み」を押します。データは消えず、表示だけが減ります。

4. 画面イメージ

左メニュー「日々の運用 → 日報」を開いたあとの画面です。オレンジの番号は下の表と対応します。

場所すること
1対象月前月 / 年月 / 翌月 / 表示。見る月を変える
2データ取り込みExcel または CSV の取込画面を開く（権限がある人だけ）
3検索と絞り込み案件・会社・パートナーの文字、締日、状態、入力あり/なし
4集計カード対象案件 / 未入力 / 作業中 / 確認待ち / 完了 / 要対応。クリックで状態だけ絞る
5一覧表案件No、案件名、企業、パートナー、締日、入力進捗、月次承認状態
6入力ボタンその案件の日報入力へ進む。行のダブルクリックでも同じ

5. 何をどこに入れるか

この画面で「保存する勤務実績」はありません。探すための条件だけ入れます。

項目入れる場所例
対象月画面上部の年月2026-08
キーワード「案件・会社・パートナーを検索」東都、山田
締日締日の選択5日、末日
月次の状態状態の選択、またはカード未入力、差戻し
入力の有無入力状況未入力
列ごとの絞込見出し直下の「絞込」案件名の一部

列見出しをクリックすると並び順が変わります。操作列の副作用（削除など）はダブルクリックでは起きません。

6. 操作手順

  1. アプリにログインする
  2. 左メニューの「日々の運用」から 日報 をクリックする
  3. 対象月を合わせ、「表示」をクリックする
  4. 必要ならカードまたは検索で件数を絞る
  5. 対象行をダブルクリックする、または右端の 入力 をクリックする

次の画面は 日報入力 です。

7. データ取り込み（一覧からのサブ画面）

紙やExcelの内容をまとめて下書きへ載せるときは、一覧右上の「データ取り込み」を使います。管理者と総務だけが操作できます。

場所すること
1対象年月取り込む月を指定する
2ファイル.xlsx または .csv（50MBまで）を選ぶ
3アップロードして確認原本を保存し、列の対応と内容確認へ進む
4取込履歴同じ月の過去取込と状態を見る
注意。 ファイルに書かれた請求額・支払額は使いません。反映後もシステムの料金設定で再計算します。確認済み・承認済みの日報は上書きしません。同じ内容の二重取込は警告が出ます。

8. 注釈・注意

注釈。 集計カードは絞り込みです。件数を減らしてもデータは削除されません。もう一度同じカードを押すと絞り込みが外れます。
注釈。 「データ取り込み」が無い場合は、権限が管理者・総務ではありません。経営者は原本の閲覧側です。
注意。 隣のメニュー「日報提出」は、パートナーから届いた日報の受領確認です。この一覧の入力進捗とは連動しません。
