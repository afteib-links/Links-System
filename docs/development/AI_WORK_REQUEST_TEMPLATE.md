# AI開発依頼テンプレート

新しいAIチャットへ、次の枠を埋めて依頼する。AIは最初に `AGENTS.md` と指定仕様を読んでから作業する。

```text
作業ID: GitHub Issue #<番号>（未作成なら「作成予定」）
担当AI: Cursor / Antigravity / Codex / その他

目的:
  <業務上または技術上の達成したいこと>

対象仕様:
  <仕様MDのパス。例: 仕様MD/09_日報・精算・帳票_業務要件.md>

変更してよい範囲:
  <ディレクトリ・ファイル・責務>

変更してはいけない範囲:
  <他AIが作業中の範囲、既存migration、data/、.env等>

完了条件:
  <画面/API/文書として何ができれば完了か>

確認方法:
  <実行するテスト、画面操作、レビュー観点>

未確定事項:
  <推測で決めず、質問または決定ログへ残す内容>
```

依頼を受けたAIは、作業開始時に対象IssueまたはDraft PRへ、担当AI・予定する編集範囲・想定する検証方法を記録する。作業終了時は、同じ場所に未完了事項と次の作業を追記する。
