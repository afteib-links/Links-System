# 日報・OCR・追加項目・年度締めの利用手順

## 日報入力

日報管理で企業・案件・パートナーと対象月を選びます。期間表示を確認し、時間入力では開始→終了→休憩をTabで連続入力します。`230`、`2.30`、`２．３０`は02:30、`1730`は17:30です。`2.3`は2.03または2.30へ直してください。翌日分は28:00など47:59まで使えます。

Alt＋↓で時分の選択、F2で選択行の詳細、Ctrl＋Sで保存します。距離・経費は「全項目入力」で入力します。非表示分に値がある場合は件数・合計を確認できます。

既存日報は従来の暦月を保持します。締め期間の移行は差分を確認して理由を入力した未確定期間だけが対象です。20日締めの11月分は10/21〜11/20です。

## PDFからの入力

「データ取り込み」でPDFを選び、案件・様式テンプレートを指定します。初回は表・行・列の位置を保存してください。原本の行画像、OCR候補、現在値・反映予定値を並べて確認します。

日付が不明な行は必ず確認し、同日に複数の作業がある場合は反映先を選びます。行と項目を選択して「選択内容を反映」を押すまで日報は変わりません。既存行と要確認行は初期OFFです。既存行の再取込には理由が必要です。空欄で既存値は消えません。OCRが使えない場合も原本を見て手入力できます。

## 追加項目・自家用燃料費

日報の期間操作、日別詳細、またはマスター設定の「追加項目・燃料設定」から開きます。日別/締め期間別の項目を複数登録し、請求・支払の対象と金額を指定できます。

燃費はパートナー→全社、往復距離は案件→パートナー、地域は案件→パートナー→全社の優先順です。適用日付きで設定してください。価格履歴に都道府県・価格日・レギュラー単価を登録し、計算基準日を選びます。欠測時は過去価格の採用または手動価格の理由が必要です。

燃料費は往復距離÷燃費×燃料単価を日額で切り上げ、同一案件の出勤日数を掛けた税込額です。35km÷12km/L×170円/L、20日なら9,920円です。日報の業務走行距離とは別です。プレビューの設定元・対象日・日数・金額を確認して保存します。出勤日を変更した後は燃料を再計算してください。

gogo.gsからの自動取得は利用許諾・取得方法の確認待ちです。それまでは価格を手動登録します。毎日の取得予定時刻は日本時間で保存できます。

## 年度締め

事務作業または収支分析の「年度締め」から開きます。「2026年11月期」は2025年12月締め〜2026年11月締めと11月末調整です。

1. 事務が集計を作成し、初年度の前年11月締日後の計上額、または該当なしを確認します。
2. 通常集計・11月締日後の実績を確認します。月額固定費・月間距離・期間一括項目は案件ごとに計上額と理由を入力します。該当なしも0円と理由を確認します。
3. 差分を再計算して下書きを保存し、未確認事項と理由を確認して営業へ申請します。
4. 案件の担当営業が自分の対象を確認します。営業未設定の場合は管理者が代行します。
5. 管理者または経営者が確定し、年度専用の請求/支払保存PDFを作成します。

通常の請求・支払、入出金予定、前払・繰越消化は実行しません。通常12月分の業務は従来どおり進めます。前年の11月締日後の額を次年度に含めるかは、年度画面の設定で指定できます（初期値は除外）。

確定内容の変更は理由付き訂正版を作成します。旧版とPDFは残ります。訂正版下書きの保存時に対象年度の入力保護を解除するため、元日報を訂正し、再計算・再申請・再確定まで行ってください。通常締めと年度保存の差額は明細で確認できます。

## 運用前に残る確認

対象の匿名手書き用紙で正解率・修正回数・手入力との総作業時間を測定し、QNAPと2GB ASUSTOR実機で性能を確認してください。開発PCの匿名活字PDF試験は実施済みですが、この実機・実手書き評価を代替するものではありません。
