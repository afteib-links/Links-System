# 実データ・秘密情報の扱い

Links-Systemは請求額、支払額、口座、個人情報を扱うため、AI・端末・GitHub間でデータを移動する前にこのルールを確認する。

## リポジトリへ入れないもの

- `.env`、APIトークン、セッション秘密鍵、NAS接続情報
- MariaDBの実データ、DBダンプ、バックアップ
- 顧客・パートナーの氏名、住所、電話番号、口座、個人番号等を含む表
- 実運用のExcel、PDF帳票、FAX・日報画像、FB振込ファイル、ログ出力

`.gitignore`に該当していても、AIへの添付・Issue本文・PR本文・コミットメッセージへ記載してよい理由にはならない。

## テストデータ

- テストには架空の会社名・人物名・口座・金額を使い、必要最小限の行数にする。
- 実データでしか再現できない問題は、まず項目名・件数・金額帯を匿名化して共有する。
- 実ファイルを一時的に確認する必要がある場合は、GitHubへ追加せず、目的・保管場所・削除時期をユーザーと確認する。
- PDF・Excel・画像をもとに仕様を作るときは、ファイル自体ではなく、決定された要件を `仕様MD/` に記録する。

## 実DB・NAS操作

- 実DBの移行、削除、復元、NAS同期は、バックアップと復旧手順を確認してから行う。
- AIは実データの削除・上書き・外部送信を独断で行わない。
- 本番へ反映できるのは、レビュー済みで `main` にマージ済みの変更だけである。
