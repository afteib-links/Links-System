# 画面イメージ

UIの見た目・構成の参照用画像を置きます。

| ファイル | 内容 |
|----------|------|
| （追加予定）`日報画面（一覧）.png` | 日報管理の一覧画面イメージ |
| `日報提出一覧_モック.png` | 日報提出一覧の確認用画面イメージ（先払型3サイクル） |
| `日報提出一覧_指摘.jpg` | ユーザー指摘付きの確認画像（案件情報・パートナー主表示・不要セル削除・遅延手修正） |

- ファイル名は画面名で揃える（例: `日報画面（一覧）.png`）
- 実装時の見た目合わせ・見直し時の参照に使う
- 正式な画面仕様は `個別機能仕様書：*.md` を正とする
