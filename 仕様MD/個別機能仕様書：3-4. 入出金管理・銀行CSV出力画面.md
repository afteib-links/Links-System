# 個別機能仕様書：3-4. 入出金管理・銀行CSV出力画面

> **状態**: 2026-09-06 Issue #79で初版確定  
> **正本**: `10_入出金管理・FB_業務要件.md` の管理回・予定・実績・銀行別CSVの分離を優先する。

## 1. 目的

月6回の入出金管理回を、カレンダーと一覧で確認し、同一管理回の出金予定を振込元口座に対応する銀行CSVとして安全に出力する。画面構成は添付された詳細画面仕様書の「収支管理・総振FB出力」を参考にするが、実残高・銀行API・収支分析は本画面に含めない。

## 2. 画面構成

### 2.1 共通上部

- 画面名「入出金管理・FB出力」
- 対象年月の前月・翌月・再読込
- キーワード検索
- 「カレンダー」「一覧」の表示切替
- 管理回、入出金区分、状態の絞り込み

### 2.2 カレンダー

- 日曜始まりの月表示とし、日ごとに入金合計、出金合計、差引、主な予定を表示する。
- 5日、10日、15日、20日、25日、末日回の基準日を表示する。
- 日付を選択すると一覧と右側サマリーを同じ日付で絞り込む。

### 2.3 一覧

| 項目 | 内容 |
|---|---|
| 選択 | 同一管理回の出金・予定作成済みだけ選択可能 |
| 管理回／予定日 | 業務上の所属と実際の予定日を分けて表示 |
| 支払先／件名 | 予定のスナップショット名称と根拠 |
| 金額 | 予定額と実行額、差額 |
| 振込先 | 銀行・支店・口座のマスク表示 |
| データ確認 | 出力可能／要修正と不足項目 |
| 状態／操作 | 予定、出力済み、保留、実行済み、取消と既存操作 |

### 2.4 右側サマリー

- 選択日または対象月の入金合計、出金合計、差引
- 選択件数、選択金額、銀行データ不備件数
- 振込元口座選択
- 最近のCSV出力履歴、再ダウンロード、取消

狭い画面では一覧の下へ移動し、生成ボタンは画面下部に固定する。

## 3. 銀行CSV作成

1. 一覧で同一管理回の予定を選択する。
2. 振込元口座と振込指定日を指定する。
3. サーバーで予定状態、口座情報、公開済みプロファイル、列定義を検証する。
4. 列名と先頭行を含むプレビュー、件数、合計額、エラーを表示する。
5. エラーが0件の場合だけCSVを生成し、対象予定を「出力済み」にする。
6. 銀行処理後、既存の実績登録から実行日・実行額を登録する。

## 4. フォーマットマスター

- 銀行系列ごとにプロファイルを持ち、ファイル設定と列設定を版管理する。
- 編集は常に下書き版で行い、列が1件以上あり設定検証を通過した版だけを公開できる。
- 列の参照元はシステムが許可した項目、または固定値に限定する。SQL、JavaScript、任意式は登録できない。
- 公開時に直前の公開版を廃止扱いにするが、過去バッチからの参照と再ダウンロードには残す。
- マスター編集は管理者・システム担当者、CSV利用は入出金管理権限を持つ管理者・経営者・総務とする。

## 5. 異常系

- 選択後に他利用者が予定を更新・出力した場合は生成を中止し、再読込を求める。
- 不備行の自動除外、公開済み版の直接編集、実行済みを含む出力取消は禁止する。
- マスター変更後も、過去バッチは保存済み列定義と行スナップショットから同一バイト列を再生成する。
- 銀行正式仕様との取込試験が未完了の版は、名称に「未検証」を表示し公開しない。

## 6. 対象外

- 銀行残高の取得、銀行APIによる直接振込、銀行明細取込・自動消込、収支グラフ、作成者と承認者の分離。
