# 運送業務基幹システム：全体方針・共通ルール定義書

## 1. システム全体の方針
* **目的**: Excel管理されている運送業務（案件・パートナー・収支）のWebシステム化
* **開発スコープ**: 1週間での初期稼働を目指す（MVP開発）
* **技術スタック**: HTML5 / CSS3 / JavaScript (フロントエンド中心)
* **基本単位**: 「1案件×1パートナー」を一対とした日報・請求・支払管理

## 2. 業務・計算ルール（最重要）
* **基本勤務時間と稼働判定**:
  * 一律ではなく、**案件ごとに「拘束時間ベース」か「実働時間ベース」かを指定**し、基本となる時間数も案件マスターにて定義する。
* **時間超過の計算**:
  * 定められた基本勤務時間超を対象とし、「15分未満切り捨て」等で超過数を算出する（丸めルールは案件により変動あり）。
* **金流ルール（請求側）**:
  * 同一企業の複数案件は、「1枚の請求書」にまとめて出力する（個々の請求は明細として添付する場合あり）。
* **金流ルール（支払側）**:
  * 同一パートナーの複数案件は、「案件ごとに個別の支払明細」を作成し、合算を禁止する。
* **定額控除（自動差し引き）**:
  * パートナー支払時、毎月自動で「事務手数料：1,100円(税込)」と「安全協力会費：8,800円(非課税)」を控除する。
* **分割（先払い）と最終振込額の計算**:
  * 先払いは月3回サイクル（5,10 / 15,20 / 25,末）で管理。
  * 実際の支払時には、**「月次支払額 － (先払い合計額 ＋ 振込手数料合計) － 定額控除 ＝ 最終実振込額」**として算出する。
