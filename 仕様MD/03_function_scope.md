# 運送業務基幹システム：機能一覧・スコープ定義書（MVP）

1週間後の初期稼働に向けて、以下の機能を最優先で実装する。

## 1. マスタ管理（基本設定）
* 企業管理画面
* パートナー管理画面
* **改定履歴付き案件マスター画面**: 基本案件からの複製機能、期間別単価・条件設定機能、分割払い設定機能。

## 2. 日報・業務管理（日々の運用）
* **日報登録・一覧画面（管理者用・スマホ対応）**:
  * 勤務日、開始・終了時間、休憩時間、経費（交通費・通行料等）の入力。
  * 超過時間の即時計算。
  * 期間別単価の自動適用と、例外時の金額手入力（オーバーライド）機能。

## 3. 請求・支払管理 ＆ 先払い管理（精算処理）
* **先払い管理**: 月3回サイクルの先払い実績入力・管理。
* **請求管理**: 締日ごとの集計、企業別請求書合算発行、**締め処理による金額の固定化（スナップショット）**。
* **支払書・明細書出力**:
  * 定額控除および先払い実績・振込手数料の自動差し引き計算。
  * **「1枚の帳票で、上下に分割して表示」**: 上部に本来の支払明細、下部に先払い等の控除実績と最終実振込額を記載する一体型レイアウトで出力。

## 4. 認証・権限管理（基盤）
* **ログイン**: 簡易ID/パスワード。
* **ユーザー管理**: ユーザー作成・無効化、機能ごとの利用制限。
* 詳細は `07_auth_and_permissions.md` を参照。
