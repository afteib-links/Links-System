# 開発指示：4-1. 収支分析画面

> **状態**: 画面・API実装（2026-09-06）。CSV/PDF・KPIグラフは対象外。  
> **画面イメージ**: [`html_prototypes/13_analytics.html`](../html_prototypes/13_analytics.html)、[`画面イメージ/`](画面イメージ/)  
> **計画**: [`計画/23_収支分析3表.md`](計画/23_収支分析3表.md)  
> **入出金管理との関係**: 旧「収支管理」は入出金・FBへ統合済み。本画面は分析専用であり、入出金カレンダーとは別機能とする。  
> **旧K-04**: 年度KPI・月別グラフは本仕様の対象外。

## 1. 画面の目的

担当者ごとの企業・パートナーの収支、企業別利益率の時系列、稼働日の時系列を、エリア・担当者で抽出して見る。

## 2. 画面構成

サイドバー分類に **分析** を追加し、機能名は **収支分析**。1画面・3タブ。

| タブ | 期間 | 行の粒度 |
|------|------|----------|
| 収支分析一覧表 | 対象月1つ | エリア → 担当者 → 企業 → パートナー |
| 企業別利益率一覧表 | 複数月（左が最新） | エリア＋担当者の区切りの下に企業 |
| 稼働日一覧表 | 複数月（左が最新） | エリア区切りの下に 担当者・企業・パートナー |

共通フィルタ: エリア、担当者。収支分析一覧は対象月セレクタを持つ。利益率・稼働日は月範囲（既定は直近12か月。全期間は表内横スクロール）。稼働日は企業フィルタも置く。

権限案: 管理者・経営者・総務（入出金と同じ）。営業の自担当限定は未決。

## 3. 収支分析一覧表

### 3.1 折りたたみ

独立した表示切替（アコーディオン）とする。

| 操作 | 動作 |
|------|------|
| エリアで畳む | エリア行だけ残し、担当者以下を隠す |
| 担当者で畳む | 担当者行まで残し、企業以下を隠す |
| 企業で畳む | 企業行まで残し、パートナー行を隠す |
| 区分で畳む | パートナー行の代わりに契約区分（外注／給与）の小計行を出す。**仮置き**。別意味なら修正する |
| すべて展開 | パートナー行まで出す |

同時ONのときは上の行ほど強い（エリアで畳むが最優先）。

### 3.2 合計行

独立チェックで、合計**額**を出すか出さないかを選ぶ。

- エリア合計
- 担当者合計
- 企業合計

OFFのときは当該階層の見出しは残して金額列を空にする（行自体は階層の骨格として残す）。

### 3.3 列

| 列 | 内容 |
|----|------|
| 売上 | 日報の実効請求額の累計 |
| 請求金額（左・売上側） | 企業の発行済み請求書があればその税抜合計。無ければパートナー累計 |
| 支払 | 日報の実効支払額の累計 |
| 請求金額（右・支払側） | パートナーの発行済み支払明細書があればその税抜相当。無ければ支払累計 |
| 利益額 | 売上 − 支払 |
| 利益率 | 売上があるとき 利益額 / 売上。売上0は `—` |
| 消費税 | 請求書があればその税額。無ければ企業行はパートナー非按分の累計を出さず空、パートナー行は空 |
| 稼働日数 | 欠勤以外の稼働日カウント |

企業行の「請求書合計がある場合はその金額。違う場合はそれぞれの累計」に従い、請求書税抜と日報売上累計が異なる企業は両方の差が見えるようにする。

### 3.4 行の見た目

```text
エリア行（任意で合計額）
  担当者行（任意で合計額）
    No  企業名  …金額…
      パートナー名  …金額…
```

## 4. 企業別利益率一覧表

- 左端の月列が最新月。以降は過去へ続く。
- エリア＋担当者の区切り行の下に、No・企業名・各月の利益率（`a%`）。
- 売上0の月は `—`。
- 見出し行と左の識別列を固定し、月列だけ横スクロールする。
- **赤色表記**: 利益率がマスター設定の「利益率警告基準（%）」未満なら赤、以上なら緑。初期値は10%。基準はマスター設定（システム設定）で変更し、金額データの利益率警告と同一キー `price_matrix_profit_warning_percent` を使う。`—` は色を付けない。

## 5. 稼働日一覧表

- 1データ行 = 担当者・企業名・パートナー名と各月の日数。
- エリアの区切り行を挟む。
- 左が最新月。見出し・左列固定、月列は横スクロール。

## 6. 集計キー

- 対象月 × 企業の弊社担当（`company_manager_periods` の `our_manager`）× パートナー（個別案件経由）
- エリアは営業担当者マスタの `area_name`。未入力は「未設定」
- 対象データ: 承認済み日報と確定済み請求／支払。未確定は出さない
