# ログイン・ユーザー権限仕様（LOGIN）

> 本ファイルがログイン／ユーザー権限の **正式仕様** です。実装・変更時はここを参照し、変更があれば本ファイルも更新する。

## 1. ユーザー権限（複数選択可）

| 権限キー | 表示名 | 備考（できること） |
|----------|--------|--------------------|
| `admin` | 管理者 | すべての機能を操作できる |
| `system` | システム担当者 | システムのメンテナンスまで行うことができる（ユーザー管理・基盤設定など） |
| `executive` | 経営者 | 経営に関する処理を行うことができる（請求・支払・先払い・集計の確認など） |
| `soumu` | 総務 | 経営やシステムに関する部分以外を対応できる（マスタ・日報・請求/支払の実務など） |
| `sales` | 営業 | 自分の担当の承認や請求書の印刷ができる |
| `partner` | パートナー | 日報入力ができる |
| `company` | 企業 | 請求書のダウンロードなどができる |

* 1人のユーザーに **複数の権限** を付与できる。
* 付与された権限の和集合で、利用可能機能を判定する。
* `admin` が1つでも付いていれば全機能を利用できる。

### 権限 → 利用機能の対応

| 機能キー | 表示名 | 利用できる権限 |
|----------|--------|----------------|
| `companies` | 企業マスタ | admin, system, soumu |
| `partners` | パートナーマスタ | admin, system, soumu |
| `projects` | 案件マスタ | admin, system, soumu, sales |
| `daily_reports` | 日報 | admin, system, soumu, sales, partner, executive |
| `advances` | 先払い | admin, executive, soumu |
| `invoices` | 請求 | admin, executive, soumu, sales, company |
| `payments` | 支払 | admin, executive, soumu |
| `users` | ユーザー管理 | admin, system |

> 営業の「自分の担当のみ」、企業の「自社請求のみ」などのデータ絞り込みは、各業務画面実装時に追加する。

## 2. ユーザー項目

| 項目 | フィールド | 必須 | 備考 |
|------|------------|------|------|
| No | `user_id` | 自動 | 自動採番 |
| ID | `login_id` | ○ | ログインID（半角英数字・._-） |
| 名 | `display_name` | ○ | 表示名 |
| 権限（複数可） | `roles` | ○ | 上記権限キーの配列。1つ以上 |
| パスワード | `password_hash` | ○ | ハッシュ保存 |
| 所属部署（複数可） | `departments` | － | 文字列配列 |
| 所属エリア（複数可） | `areas` | － | 文字列配列 |
| 有効フラグ | `is_active` | ○ | 無効時はログイン不可（追加項目） |
| 作成/更新/削除 | `created_at` 等 | 自動 | 共通項目 |

## 3. ログイン動作

* ログインID + パスワードで認証する
* 無効ユーザーはログイン不可
* 成功後、セッションにユーザー情報・権限・導出された利用機能を保持する
* 画面メニューとAPIの両方で権限を判定する

## 4. ユーザー管理

* `users` 機能権限を持つユーザー（管理者・システム担当者）が管理する
* 作成・編集・無効化・削除（論理削除）が可能
