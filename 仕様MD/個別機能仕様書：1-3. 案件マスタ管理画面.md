# 1-3. 案件マスタ管理画面（基本案件・個別案件）

## 参照関係

| 文書 | 役割 |

本画面の **金額・単価** は `project_revisions` への埋め込み改定ではなく、**`price_sets` / `price_set_lines`** を正とする。`project_revisions` はレガシー参照用。

---

## 1. 目的

- **基本案件（テンプレート）**: 企業ごとの案件の型・稼働条件のひな形を登録する。金額は **テンプレ用 PriceSet** を複数（適用期間付き）で持つ。
- **個別案件（運用）**: 基本案件から複製または新規で作成し、パートナー・車両等の実運用情報を持つ。金額は **案件専用 PriceSet**（作成時にテンプレからディープコピー）を編集する。

---

## 2. 機能キー・メニュー（D-01）

| 機能キー | メニュー名 | 内容 |
|----------|------------|------|
| `base_projects` | 基本案件 | テンプレ一覧・登録・編集・案件作成 |
| `projects` | 個別案件（案件） | 個別一覧・登録・編集 |

企業マスタからは `company_id` 付きで基本案件一覧を開く。パートナーマスタからは `partner_id` 付きで個別案件一覧を開く。

---

## 3. 画面A：基本案件

### 3.1 一覧

- **絞込**: 企業（任意）
- **列**: No、企業、テンプレ名、デフォルト担当、稼働形態、締日、操作
- **共通操作**: 列見出しソート、見出し直下の列別絞り込み、行選択、行ダブルクリックによる編集
- **操作**:
  - **編集**: 詳細画面へ
  - **案件作成**: `POST /api/projects/base/:id/create-project` — 属性コピー＋**PriceSet/行のディープコピー**（D-02）
  - **削除**: 基本案件のみ論理削除。紐づく **テンプレ用 `price_sets` のみ**論理削除（既存個別案件の PriceSet は残す）

### 3.2 登録・編集

- **属性項目（基本案件・個別案件と同水準 D-04/D-05）**:
  - 企業（必須）、テンプレ名（必須）、デフォルト担当、業種
  - 基本勤務時間、時間種別
  - 稼働形態、日報カウント区分、残業計算区分
  - 開始／終了時刻、拘束時間、休憩
  - 支払区分、分割単価、運用開始日、締日
- **金額データセクション**（`price_set_id` 単一 FK セレクトは **使わない**）:
  - 当該 `base_project_id` に紐づく PriceSet 一覧（名称、適用開始・終了、行数）
  - **＋ 金額データ追加** / 行の **編集** → 金額データ管理機能へ遷移（`base_project_id`・`company_id` 固定、`returnTo` で戻る）
  - 登録・更新は金額データ API。**期間重複可**（日報は適用開始日が新しいセットを優先）
  - **コピー**: 行ごとにコピー → 新しい適用開始日を指定して改定登録

### 3.3 案件作成後の UX

- コピーした PriceSet 件数をトースト等で表示する。

## 4. 画面B：個別案件

### 4.1 一覧

- **絞込**: 企業、パートナー（任意）
- **列**: No、企業、パートナー、基本案件テンプレ名、支払区分、締日、操作
- **共通操作**: 列見出しソート、見出し直下の列別絞り込み、行選択、行ダブルクリックによる編集
- **操作**: 編集、削除（案件＋改定履歴＋当該 `project_id` の PriceSet/行を論理削除）

### 4.2 新規登録

- **テンプレ反映（D-03）**: 基本案件テンプレート選択 → 属性をフォームに反映（金額は PriceSet セレクトではなく、保存時に **ディープコピー**）
- **属性項目**: 企業（必須）、基本案件、パートナー、車両所有元（企業／パートナー）、車両、担当、業種＋基本案件と同水準の稼働・時間項目
- **車両選択**: 所有元を企業にした場合は案件企業の企業車両、パートナーにした場合は案件パートナーの所有車両を部分一致検索して選ぶ。パートナー未選択時はパートナー車両を選べない
- **初回改定（任意）**: レガシー `project_revisions` 用。新規案件では **非推奨**（金額は PriceSet を正とする）
- `base_project_id` 指定で保存した場合、テンプレの全 PriceSet/行を案件用に複製する

### 4.3 編集

- 属性は上記と同様（`price_set_id` セレクトなし）
- 車両所有元、企業、パートナーを変更して現在の車両が新しい所有元に属さなくなった場合は選択を解除し、再選択を求める
- **金額データセクション**: `project_id` 紐づき PriceSet 一覧・追加・**コピー**・編集（金額データ管理へ深リンク）。期間重複可
- **改定履歴ブロック**: **参照のみ（レガシー）**。説明文で「金額の正は上の金額データ」と明示。新規改定入力・削除は **非推奨**（仮組では UI から除去）

### 4.4 基本案件改定のカスケード（旧仕様からの変更）

- 旧指示: 基本案件の改定時に全個別案件へ `project_revisions` を自動生成する。
- **現仕様**: テンプレの PriceSet を変更しても、**既に作成済みの個別案件の PriceSet は変わらない**（ディープコピーのため）。個別側の単価変更は案件の PriceSet を直接編集する。

## 5. 金額データ管理機能との連携（E）

- 横断一覧に **連携先** 列（基本案件 No／個別案件 No）
- クエリ `base_project_id` / `project_id` で深リンク
- **詳細画面（E-03）**: 料金 **項目** ごとに月火水木金土日祝チェック ＋ **日極／時間 × 料金種別** マトリクス（請求／支払／利益率）。`price_set_lines` へ保存時に曜日展開
- **コピー**: セット全体コピー（改定）、**項目コピー**、**他セットから行取込**（上書き／マージ）
- **新規のみ既定テンプレ**: 平日（月〜金）、休日（土・日・祝）、距離超過（曜日なし・距離計算）

### E-03 対応表

| 要件 | UI |
|------|-----|
| 曜日 | 8 区分チェック（祝 = `holiday`） |
| 計算区分 | daily / hourly 行（距離は専用項目） |
| 料金種別 | マトリクス列（`price_type` マスタ） |
| 請求／支払・利益率 | マトリクス各セル |
| 基本／超過／深夜 | 種別列＋時間行；距離は距離超過項目 |

詳細データモデルは `05_project_price_relationship.md` §9。

## 6. データ構造（画面が触る主テーブル）

詳細は `05_project_price_relationship.md` および `02_master_definition.md`。

- `base_projects` / `projects` — 属性（`projects.price_set_id` は後方互換列。画面・計算では使用しない）
- `price_sets` — `base_project_id` または `project_id` のいずれか一方のみ
- `price_set_lines` — PriceSet あたり複数行
- `project_revisions` — レガシー（参照のみ）

---

## 7. 計算エンジン（日報連携）

- 日報保存時: `spot_amount` 優先。それ以外は勤務日で案件の PriceSet を 1 件選択し、`resolvePriceRow` で行単価を解決（曜日フォールバック順は `05_project_price_relationship.md` §5.2）。`applied_price_set_id` を記録。詳細は `04_calculation_logic.md`。
- 曜日フォールバック順（行未登録時）: 平日 → 半日 → 土 → 日 → 祝 → その他（祝日マスタ連動は次段）
- 本画面に属さないが、将来の LinksSys 計算（時間外・距離・端数）は `projects` 属性と PriceSet 行を入力とする。
