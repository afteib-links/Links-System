# Links-System（運送業務基幹システム）仕様

Excel管理の運送業務（案件・パートナー・収支）をWeb化するシステムの仕様書置き場です。

## 仕様の扱い方（最重要）

このフォルダ（`仕様MD/`）が **システムの正式な仕様の参照元** です。

## AI ツール共通（Cursor / Antigravity）

作業開始前に必ず参照する。

| ファイル | 内容 |
|----------|------|
| リポジトリ直下 [`AGENTS.md`](../AGENTS.md) | 共通入口 |
| [**00_現状スナップショット.md**](00_現状スナップショット.md) | いまの main・フェーズ・PR |
| [**00_AI共通_開発ガイド.md**](00_AI共通_開発ガイド.md) | Git・ブランチ・両ツールでの開発ルール |

機械確認: `./scripts/print-project-status.sh`

1. **実装・調査・設計は、必ずこのフォルダ内の仕様を参照する**
2. **仕様を変える判断をしたときは、コードだけでなく、このフォルダ内の該当MDも同じ内容に更新する**
3. 決定事項・方針変更は `05_decision_log.md` に追記する
4. 画面単位の詳細は `個別機能仕様書：*.md` を正とする
6. 実装計画は `計画/` に保管し、新しい計画も必ずそこに追加する

> コードと仕様MDに差がある場合は、仕様MDを先に直し、その内容に合わせて実装する。

## 重要なお知らせ

個別機能仕様書には「HTML5 SPA + IndexedDB」とあります。  
実運用は **4名同時利用・共有MariaDB** のため、データ保存は IndexedDB から変更します。  
**本番＝QNAP TS-464**、**テスト＝ASUSTOR AS3202T**（手順は `計画/07_AsustorテストNAS配備手順.md`）。  
詳細は `06_development_environment.md` を参照してください。
