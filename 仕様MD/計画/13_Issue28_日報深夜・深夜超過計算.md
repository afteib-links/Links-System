# Issue #28 日報の深夜時間・深夜超過計算

> **状態**: ヒアリング中・N-01一部確定
> **対象Issue**: [#28 日報の深夜時間・深夜超過計算を確定する](https://github.com/afteib-links/Links-System/issues/28)
> **目的**: D-01から分離した深夜計算について、DB・API・計算処理へ固定する前に業務ルールを確定する。

## 1. 確定済みの前提

- 勤務時刻は勤務日を基準とする48時間表記で入力し、最大は`47:59`とする。
- 例として翌日4時は`28:00`と入力し、翌日の別日報へ自動分割しない。
- 休憩は開始・終了を個別登録せず、1日の合計休憩時間を`H:MM`形式で入力する。
- 拘束時間、実働時間、時間調整、通常超過、不足時間はD-01で定義済みである。
- 請求側と支払側では、単価、計算方式、対象可否、時間・金額の丸め条件を独立して設定できる構造とする。
- 新規案件の時間丸め初期値は15分、丸め方式は切り捨て、時間丸め段階は日ごとである。ただし案件条件で変更できる。
- 現行コードやプロトタイプにある`22:00～05:00`、0.25時間単位、ダミー単価は正式仕様ではない。

## 2. 用語の仮定義

| 用語 | 仮の意味 | 状態 |
|---|---|---|
| 深夜対象時間 | 契約で定めた深夜時間帯と、計算対象勤務時間が重なる時間 | 要確定 |
| 通常超過時間 | 契約の基準時間を超えた時間 | D-01で計算単位を確定済み |
| 深夜超過時間 | 深夜対象時間と通常超過時間の両方に該当し、日報の深夜超過欄へ分類する時間 | 専用料金を適用。分類順序は要確定 |
| 深夜料金 | 深夜対象時間に適用する請求・支払明細 | 計算方式・単価は要確定 |
| 深夜超過料金 | 深夜かつ超過に該当する時間へ適用する明細 | 独立明細か重複加算か要確定 |

## 3. 48時間表記での判定例

以下は判定方法を確認するための例であり、時間帯や結果は未確定である。

| 勤務入力 | 仮に深夜帯を22:00～翌5:00とした場合の候補 | 確認点 |
|---|---|---|
| `20:00～28:00` | `22:00～28:00` | 翌5時を`29:00`として同じ勤務日に判定するか |
| `23:00～31:00` | `23:00～29:00` | 深夜帯終了後の時間を通常時間へ戻すか |
| `20:00～47:00` | 初日夜と翌日夜の2区間が候補 | 24時間を超える勤務で深夜帯を繰り返し適用するか |

## 4. 決定が必要な事項

### N-01 深夜時間帯

- **決定済み**: 全案件共通の固定時間帯にせず、案件条件で開始・終了を設定可能にする。
- **決定済み**: 請求側と支払側で異なる時間帯を設定できる。
- **決定済み**: 新規案件の初期値は勤務日基準の`22:00～29:00`（翌朝5時）とし、両側とも変更可能にする。
- **決定済み**: 基本業務が深夜で深夜料金を通常料金へ含む契約等では、深夜料金を別途計算しない設定を可能にする。
- **決定済み**: 請求側・支払側ごとに、深夜計算区分として「別途計算」「基本料金に含む」「対象外」を選択できる。
- **決定済み**: 「基本料金に含む」では深夜対象時間を社内の計算根拠として計算・保存するが、別料金を加算せず外部帳票へ深夜明細を表示しない。
- **決定済み**: 「対象外」では深夜時間自体を計算・保存・表示しない。
- **決定済み**: 請求側・支払側それぞれに複数の深夜時間帯を設定できる。
- **決定済み**: 新規案件は`22:00～29:00`の1区間だけを初期登録する。
- **決定済み**: 24時を超える終了時刻は勤務日基準の時刻へ展開し、24時間を超える勤務では設定した各深夜帯を24時間ごとに繰り返して判定する。
- **決定済み**: `20:00～47:00`に初期値を適用した場合は、`22:00～29:00`と`46:00～47:00`を深夜対象候補とする。
- **決定済み**: 深夜計算区分が「対象外」の側では、深夜帯の判定を行わない。

### N-02 休憩と時間調整

日報は合計休憩時間だけを保持するため、休憩が深夜帯に含まれるかを時刻から自動判定できない。

- **決定済み**: 日報へ「深夜帯内休憩時間」を追加する。
- **決定済み**: 1分単位で入力し、初期値は`0:00`とする。
- **決定済み**: 深夜帯内休憩時間は深夜対象時間からだけ控除する。
- **決定済み**: 合計休憩時間を超える入力は禁止する。
- **決定済み**: 深夜帯と勤務時間が重なり、合計休憩時間が正数なのに深夜帯内休憩時間が`0:00`の場合は警告するが、明示的な続行により保存・日次確認を許可する。
- **決定済み**: 深夜計算区分が「対象外」の側では使用しない。
- **決定済み**: 請求側と支払側の深夜時間帯が同じ場合は共通入力欄を1つ表示し、異なる場合は請求用・支払用へ自動分離する。
- **決定済み**: 両側の条件が再び同じになった場合は値を失わず共通入力へ自動的に戻す。
- **決定済み**: 自動分離・自動統合は、利用者、日時、切替前後の表示状態、判定根拠となった条件差を操作履歴へ保存し、一般的な操作履歴と同じ期間保持する。

- **決定済み**: 自動計算した深夜対象時間は直接上書きしない。
- **決定済み**: 「深夜時間調整」を別項目とし、正負の1分単位で入力する。調整理由は必須とする。
- **決定済み**: 調整後深夜時間は0分以上かつ当該側の計算対象勤務時間以下に制限する。
- **決定済み**: 請求側と支払側の深夜計算条件が同じ場合は共通入力、異なる場合は自動分離し、条件が同一へ戻れば値を維持して共通入力へ戻す。
- **決定済み**: 自動計算値、調整値、調整後時間、理由、入力者、日時と入力欄の自動分離・統合を操作履歴へ保存する。

### N-03 通常超過と深夜超過

- **決定済み**: 日報画面の「超過」「深夜」「深夜超過」を独立した排他的な計算明細とする。
- **決定済み**: 超過欄の最終時間には超過料金、深夜欄には深夜料金、深夜超過欄には深夜超過専用料金を適用する。
- **決定済み**: 各料金設定には請求額・支払額を別々に登録する。
- **決定済み**: 深夜超過時間へ超過料金と深夜料金を自動重複加算しない。必要な割増を含む単価を深夜超過専用料金として登録する。
- **決定済み**: 自動候補と理由付き調整を反映した最終時間を、各入力エリアの計算数量として保存する。
- **決定済み**: 時間は1分単位で、深夜帯かつ基準時間超過を「深夜超過」、基準時間超過のうち深夜超過を除いた時間を「超過」、深夜対象時間のうち深夜超過を除いた時間を「深夜」へ自動分類する。
- **決定済み**: 同じ1分を複数の入力欄へ重複計上しない。
- **決定済み**: 「深夜」と「深夜超過」はそれぞれ独立して「別途計算」「基本料金に含む」「対象外」を請求側・支払側ごとに設定できる。通常深夜を基本料金へ含め、深夜超過だけを別途計算する契約も扱う。

### N-04 計算方式と単価

- **決定済み**: 請求側・支払側それぞれに「別途計算」「基本料金に含む」「対象外」を設定できる。
- 固定額、時間単価、基準単価への割増率、既存料金への加算額のどれを扱うか。
- 深夜料金と深夜超過料金に異なる計算方式を設定できるか。
- 請求側と支払側で、対象可否、計算方式、単価、割増率、計算対象時間を独立させるか。
- 深夜時間を日報入力者が直接上書きできるか、調整明細だけを許可するか。

### N-05 丸め

- 深夜対象時間と深夜超過時間へ、案件の時間丸め条件を共用するか、専用条件を設定できるか。
- 丸めの順序を「時間帯抽出→休憩控除→通常超過との交差判定→時間丸め」としてよいか。
- 金額丸めは深夜・深夜超過の各明細へ適用するか、日合計・月合計後も選択可能にするか。
- 請求側と支払側で異なる丸め条件を許可するか。

### N-06 他の料金区分との重複

- 土曜、日祝、案件独自休日の料金と深夜料金を重複加算するか。
- 研修料金と深夜料金を重複加算するか。
- スポット・任意作業料金と深夜料金を重複加算するか。
- 日報で手動選択した料金区分により、深夜計算の対象可否や優先順位を切り替えるか。
- 重複時の優先順位を契約条件で設定可能にするか。

### N-07 保存・監査

最低限、次を計算結果へ保存する候補とする。

- 適用した契約条件・PriceSet・料金行のIDと表示名
- 請求側・支払側それぞれの深夜時間帯、対象可否、計算方式、単価・割増率
- 勤務時間と深夜帯の交差区間
- 休憩・時間調整の反映方法と反映前後の時間
- 通常超過時間との重複区間と、加算・置換・対象外の判定
- 丸め方法・単位・段階と、丸め前後の時間・金額
- 自動計算後の手動調整、理由、入力者、日時

確定・再計算・帳票発行後の履歴は、D-01で定義したスナップショット・取消・新版発行のルールへ従う。

## 5. 最初に確認する事項

N-01の深夜時間帯・計算区分・繰り返し判定、N-02の深夜帯内休憩・深夜時間調整、N-03の入力欄別料金適用と排他的な自動分類は確定した。次にN-04の計算方式と単価を確認し、その後に丸め、他料金との重複の順で確認する。
