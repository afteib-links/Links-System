# PR / 差分レビュー記録（Antigravity・Cursor 共通）

Antigravity の検証結果や、Cursor 実装前の指摘を **PR に依存せず**残す場所。

## ファイル名

`YYYY-MM-DD_<短い題>.md`（例: `2026-08-08_PR16_金額マトリクス.md`）

## テンプレ

```markdown
# レビュー: （題）

- 日付:
- 対象: PR # / ブランチ / コミット
- レビュー: Antigravity / Cursor / 人間

## 結論

（マージ可 / 要修正 / 仕様確認）

## 指摘

| ID | 重要度 | ファイル | 内容 | 対応 |
|----|--------|----------|------|------|
| R1 | 高 | path | | 未 |

## 仕様MD への反映

- [ ] 不要 / [ ] 要（ファイル名）
```

## 運用

- Antigravity: レビュー後にここへ保存 → Cursor が実装  
- マージ後、対応済みならファイル先頭に `status: 完了` を追記
