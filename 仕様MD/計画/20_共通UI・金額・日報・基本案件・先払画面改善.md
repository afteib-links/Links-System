# 共通UI・金額・日報・基本案件・先払画面改善

## 目的

Issue #73として、共通ナビゲーションと金額表記を統一し、金額データ、日報、基本案件、先払の情報密度と操作性を改善する。

## 実装

- 全機能画面の「機能一覧へ」を削除し、画面タイトル、詳細の戻る、サイドバー導線を維持する。
- 通常金額と単価を共通フォーマッターで`￥`付き表示に統一し、入力・保存・計算の整数円仕様は変更しない。
- 金額データの料金項目でマスター連動の計算種別を複数選択可能にし、既存`mode`を後方互換で読み取る。
- 日報一覧カードを状態絞込に使用し、日報入力の操作部・列見出しを固定する。
- 基本案件詳細へ紐づく個別案件一覧を追加する。
- 先払セル内を期間・状態・入力・元値の横配置へ圧縮する。

## API

- `GET /api/projects/base/:id`の`base_project`へ`linked_projects`を追加する。
- `GET /api/daily-reports/month-projects`へ`workflow_statuses`とグループ別集計を追加し、既存`workflow_status`を維持する。

## 検証

- 単体・構文テスト、金額データ・日報・基本案件・先払のE2Eを実施する。
- 1920×1080、1366×768、430×932、390×844で表示を確認する。
- Docker再構築後に`/api/health`を確認する。
