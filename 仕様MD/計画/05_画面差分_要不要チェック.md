# 画面差分・要不要チェック

> 状態: **記入完了**（2026-07-31）  
> 作成日: 2026-07-31  
> 取り込み先: [06_機能追加仕様_画面差分取り込み.md](06_機能追加仕様_画面差分取り込み.md)  
> 目的: `仕様MD/画面一覧/` の画像と、現行仕様MD・仮組実装・これまでのヒアリングを突き合わせ、追加・変更したい項目／機能／画面構成を洗い出す。

## 使い方

各項目について、次のいずれか1つにチェックを付けてください。

- `[x] 要` … 機能追加仕様に取り込む
- `[x] 不要` … 今回は採用しない
- `[x] 保留` … 判断を先送り（理由をメモへ）

記入例:

```markdown
- [x] 要
- [ ] 不要
- [ ] 保留
- メモ: 第1優先で入れる
```

※プレビュー上でクリックしやすいよう、要／不要／保留は **1行1チェック**（縦並び）にしています。各項目でどれか1つだけ `[x]` にしてください。

参照画像はすべて [`仕様MD/画面一覧/`](../画面一覧/) 配下です。  
チェック結果は [06_機能追加仕様_画面差分取り込み.md](06_機能追加仕様_画面差分取り込み.md) に取り込み済みです。
